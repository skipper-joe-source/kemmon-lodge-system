# Website page plan

## Phase 1
| Page | Main information and actions | Users |
|---|---|---|
| Login | Username, password, login error | All staff |
| Dashboard | Availability, arrivals, departures, outstanding balances; financial totals restricted | Manager, receptionist |
| Rooms | Room number, type, rate, cleaning and maintenance status; date-based availability | Manager, receptionist |
| Reservations | Date filters, guest, allocated rooms, status; create, amend, cancel | Manager, receptionist |
| Guest details | Contact details, permitted identification details, stay history | Manager, receptionist |
| Check-in | Reservation lookup, room readiness, guest verification, deposit | Manager, receptionist |
| Guest folio | Itemized charges, payments, balance, receipt actions | Manager, receptionist |
| Check-out | Final bill, settlement, actual departure, cleaning task | Manager, receptionist |
| Housekeeping | Assigned rooms, cleaning tasks, ready status, maintenance issues | Manager, housekeeping |
| Reports | Occupancy, charges, payments, outstanding balances | Manager |
| Staff settings | Accounts, roles, activation | Manager |

## Later pages
Bar POS; products and stock; suppliers and purchases; stock counts; expenses and approvals; cashier shifts; audit log; alerts; system settings.

## Shared page behavior
Provide required-field validation, loading states, clear errors, empty states, and confirmation for destructive or financial actions. Work on desktop, tablet, and mobile. Display dates and money consistently. Financial reversals require permission and a reason. Keep personal guest information out of bar and housekeeping views.

Public guest booking and a public marketing home page are optional scope decisions, separate from the staff application.
